# UNTIS Client for Flutter

**UNTIS Client** is a Flutter-based project that wraps the [UNTIS API](https://www.untis.at/) to provide easy access to your school timetable, lessons, and related information. This project is essentially a wrapper around the UNTIS API with some missing features filled in, making it simpler to integrate UNTIS functionality into your Flutter apps.  

> ⚠️ **Note:** This is a community-driven project and **not officially supported by UNTIS**. Use at your own risk.  

---

## 🚀 Features

- Easy access to UNTIS API endpoints  
- Fetch lessons, schedules, and timetable data  
- Simplifies authentication with UNTIS servers  
- Written entirely in **Flutter** for cross-platform compatibility  
- Extendable to include missing or custom features

## 🛠️ Installation

1. Make sure you have [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.

   ```bash

   ```
3. Navigate into the project folder:
   ```bash
   cd untis_client_flutter
   ```
4. Install dependencies:
  ```bash
   flutter pub get
   ```
5. Use the client in your Flutter app by importing the package and initializing it with your UNTIS credentials.
